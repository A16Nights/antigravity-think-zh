  • 仅对外部模型生效：默认通过外接模型守卫自动识别，仅在使用通过苍蓝星轨等挂载的外部模型（如 DeepSeek、Qwen、GLM、MiniMax 等透传原生 reasoning_content 的模型）时触发；使用 Antigravity 原生模型时自动静默跳过，零额外 Token 消耗。
  • 为何无法对原生 Gemini 生效：Google Cloud Code 服务端不会将 Gemini 的原始内部思考下发到客户端，而是由云端 Thought Summarizer 压缩改写成英文第三人称摘要（并附带加密 thoughtSignature）；任何客户端提示词都无法关闭或更改云端摘要器的输出语言。
  • 原生 Gemini 替代方案：若需以中文阅读原生 Gemini 的思考摘要，请使用 苍蓝棱镜（Azure Prism） 按需翻译。
